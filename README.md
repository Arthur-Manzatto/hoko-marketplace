# hoko-marketplace!

Para criar um marketplace web moderno, confiável e focado em conversão, a melhor abordagem é uma **paleta equilibrada com base neutra e detalhes vibrantes**.

Aqui está uma recomendação de paleta baseada nas melhores práticas de **UX/UI e Psicologia das Cores** para e-commerce:

## **🎨 Paleta de Cores Recomendada**

| Função em UX | Cor | Código HEX | Psicologia e Aplicação em UX |
| --- | --- | --- | --- |
| **Primária (Marca)** | **Azul Confiança** | #013095 | Transmite **segurança, credibilidade e profissionalismo**. Essencial para marketplaces onde o usuário precisa confiar o dinheiro dele à plataforma. Use em cabeçalhos, links importantes e títulos. |
| **Ação (CTA)** | **Laranja Vibrante** | #FE6901 | Estimula a **ação, entusiasmo e senso de urgência**. Cor de alto contraste ideal para guiar os olhos do usuário diretamente para os botões de **Comprar** ou **Adicionar ao Carrinho**. |
| **Fundo Principal** | **Off-White** | #F8FAFC | Um cinza extremamente claro que **reduz o cansaço visual** (comparado ao branco puro) e serve como tela neutra para que as fotos dos produtos se destaquem. |
| **Texto Principal** | **Grafite Escuro** | #1E293B | Garante **excelente contraste e legibilidade** (atendendo às regras de acessibilidade da WCAG) sem o peso e a rigidez do preto puro (#000000). |

---

## **🟢 Cores Semânticas (Feedback do Sistema)**

Essas cores devem ser guardadas exclusivamente para comunicar estados do sistema ao usuário:

- **Sucesso (#10B981 - Verde):** Cupons aplicados, checkout concluído ou frete grátis.
- **Alerta (#F59E0B - Amarelo):** Restam
apenas
2
unidades ou avisos de envio.
- **Erro (#EF4444 - Vermelho):** Cartão recusado, campo obrigatório vazio ou produto esgotado.

---

## **📐 Como aplicar (Regra do 60-30-10)**

1. **60% da Interface (Dominante):** Use o **Off-White** (#F8FAFC) nos fundos das páginas e o **Grafite** (#1E293B) nos textos.
2. **30% da Interface (Estrutura/Marca):** Use o **Azul Confiança** (#1A365D) no menu superior, rodapé, ícones secundários e botões de menor importância (como Ver
Detalhes).
3. **10% da Interface (Conversão):** Use o **Laranja Vibrante** (#FF6B00) **apenas** nos botões principais de compra. Se tudo for laranja, nada chama a atenção.
